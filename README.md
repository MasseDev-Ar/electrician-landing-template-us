# Electrician Landing Template

Plantilla reutilizable de MasseDev para crear landing pages orientadas a electricistas, instaladores y servicios técnicos.

## Objetivo

Crear sitios rápidos, profesionales y orientados a conversión, con foco en:

- WhatsApp
- servicios
- trabajos realizados
- reputación
- zonas de cobertura
- contacto directo

## Stack

- HTML5
- CSS3
- JavaScript Vanilla
- GitHub Pages
